# .github

Holds the Twigo organization profile: [`profile/README.md`](profile/README.md)
renders on the [organization page](https://github.com/twigo).

Community health files — code of conduct, security policy, contributing guide,
issue and pull request templates — live in the product repository rather than
here. GitHub only falls back to org-level copies for repos that have none of
their own, and a second set would drift from the ones people actually read.

Product repository: https://github.com/twigo/twigo
